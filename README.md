# 🚀 SkillMart – Multi-Vendor Digital Marketplace

> Buy, Sell, and Discover Premium Digital Products

SkillMart is a full-stack **MERN** based multi-vendor digital marketplace where creators can sell and customers can purchase digital products such as UI Kits, React Templates, Source Code, E-books, Design Assets, Icons, and more.

This project is built as a production-ready application with secure authentication, payment integration, cloud file storage, email automation, and role-based access control.

# 🚀 Installation

## Clone Repository

```bash
git clone <repository-url>
```

## Frontend

```bash
cd client
npm install
npm run dev
```

## Backend

```bash
cd server
npm install
npm run dev
```

---

# 🌐 Environment Variables

Create a `.env` file inside the server directory.

```env
PORT=

MONGODB_URI=

JWT_SECRET=

EMAIL_USER=
EMAIL_PASS=

CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=

RAZORPAY_KEY_ID=
RAZORPAY_KEY_SECRET=

FIREBASE_API_KEY=
```
